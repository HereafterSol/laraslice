LaraSlice Changelog

Explore the latest features, architectural upgrades, performance optimizations, and breaking changes across LaraSlice versions.

v1.2.4 Latest Release October 2026

This milestone release brings live MySQL column reflection, conversational 1-click migrations, the visual Slice Studio orchestrator, an enterprise 15-table User aggregate with WebAuthn passkeys, and real-time DOM screen awareness.

⚡ Visual Slice Studio (`/laraslice/wizard/studio`)

Dedicated visual command center for browsing slices, aggregate entities, and live records. Features a bidirectional event bus (laraslice-slice-selected) that instantly syncs selected slice context, tables, and permissions directly into the Copilot.

📐 Real-Time MySQL Column Introspection ("What You Ask is What You Get")

The AI Copilot executes native SHOW COLUMNS FROM `{table}` queries, revealing exact SQL data types, nullability, primary/foreign/unique keys, and default values. Eliminates guesswork when querying specific tables like user_details.

➕ Conversational 1-Click Schema Migrations in Chat

Ask to add a field (e.g. "add emergency_contact in user_details"). The Copilot displays an interactive proposal card with inferred data types, non-breaking nullable defaults, enterprise recommendation chips, and a single-click "⚡ Apply Migration & Add Field Now" button that generates and runs the migration on MySQL immediately.

⌨️ Dynamic Context-Aware Slash (/) Commands

Typing / in the Copilot auto-completes slice-specific actions: /fields [table], /add-field [table], /relations, /permissions, /nav, /logs, /suggest-fields, /seed, and /wipe.

👥 Enterprise User Management Aggregate (15 Tables)

Upgraded the Users slice to a full multi-table aggregate: primary users root table with 14 child entities including user_details, user_devices, user_passkeys (WebAuthn/FIDO2 biometric login), and user_security_logs.

🛡️ Passkey Revocation & Safe Lifecycle Flow

Fixed passkey removal routing to support multi-verb dispatch (DELETE/POST/GET) and seamless redirection back to the MFA settings hub with live status alerts.

v1.1.0 Feature Release September 2026
  • Declarative Blueprint Studio: Interactive visual schema designer with drag-and-drop table relationship mapping.
  • Multi-Table Aggregate Architecture: Introduced parent-child aggregate boundaries and transaction-safe cascading updates.
  • Cross-Slice Contracts & DTOs: Type-safe interfaces ensuring slices communicate strictly via contracts without tight coupling.
  • Dual-Layer Audit Engine: User-level intrinsic record stamps paired with an immutable system ledger and automatic retention pruning (slice:audit:prune).
v1.0.0 Initial Public Release August 2026
  • 3-Layer Packaging Model (ADR-001): Core Engine, Starter Slices, and Project-specific domain slices with zero vendor lock-in.
  • Pure Blade + Alpine.js + Tailwind CSS v4: Lightweight, ultra-responsive UI shell built on BlatUI and Lucide icons.
  • CLI Generators: High-velocity artisan commands including slice:make, slice:seed, and slice:toggle.
  • Dual Web & Mobile Scaffolding: 1-click export of typed RESTful endpoints and Flutter-compatible models.
