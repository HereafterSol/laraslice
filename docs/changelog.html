LaraSlice Changelog

Explore the latest features, architectural upgrades, performance optimizations, and breaking changes across LaraSlice versions.

v2.0.0 Latest Release October 26, 2026

The Foundation Release. Mind · Body · Heart becomes the working model (intent, declared surface, runtime truth); a Standard UI/UX system makes lists, forms, hubs, documents, matrices, reports, and dashboards behave by declaration; the layout kit adds the source-shell model, fused directory chrome, a declared hub composition, and portal dashboards; the Studio grows to six modes (Plan and Operate join Port, Design, Create, Manage); and porting is gated by the 100% Replica Protocol — five gates with a per-port status file. Proven live against a running port of a production ERP, compared page-by-page with its source.

🧭 Mind · Body · Heart

system.yaml holds the system's intent, one *.ui.yaml per slice declares its surface, and slice.yaml is the sole runtime truth. slice:plan:draft drafts a Mind and Bodies from discovery — marked as drafts, never overwriting.

🖼️ The Layout Kit & Portal Dashboards

A screenshot-read audit found that token-level styling could not see composition, so the kit became a layout kit: the source's shell on ported trees, one fused filter band, ui.show.composition: overview hub pages, and portal dashboards with a welcome header, live clock + attendance punch, profile card, dual-figure stat cards, own-scope tables, and a month-grid calendar.

✅ The 100% Replica Protocol

Porting is gated, not vibes: schema parity, join-verified data truth, furniture parity, task conformance, and visual conformance read from paired screenshots. Every port keeps a REPLICA-STATUS.md and quotes its lowest gate — a token probe is explicitly not a visual gate.

v1.8.0 October 20, 2026

ONE Studio + YAML-only manifests + Default UI. The developer studios unify into one shell with four modes and a YAML diff preview before any overwrite — no silent writes. slice.yaml becomes the only manifest format, and the Default UI program makes generated and ported applications present correctly with zero hand-tuning.

v2.0.0 October 20, 2026

Major feature release: Slice YAML v0.1 (spec + JSON Schema + slice:validate), the formatter pipeline (YAML → pixels: status pills, progress bars, money breakdowns), Phase 2 DataTable classification, and non-Laravel porting — verified by porting a production Laravel ERP (85 slices) and a non-Laravel PHP system from its SQL dump (407 tables discovered). Plus runnable Kitchen Sink / CRM / HR / Shop examples and the Dev Studio Standard.

🛡️ Sanctum Migration Deduplication & SQL 1050 Protection

SliceInstallCommand now proactively checks for any pre-existing *_create_personal_access_tokens_table.php migration files before running vendor:publish. If multiple Sanctum migration files are found, it automatically deduplicates and keeps only the earliest one, eliminating SQLSTATE[42S01]: Base table or view already exists: 1050 Table 'personal_access_tokens' already exists errors during automated migrations.

v1.6.2 October 16, 2026

Major enterprise release delivering N-Tier Recursive Slice Discovery (Super-Domains & Bounded Modules), Pluggable Multi-Tenancy & SaaS Isolation, Universal Monolith Reverse-Engineering with ETL Data Streaming, Interactive Blueprint Studio Porting Suite, Declarative UI Schema with instant Slide-Over Drawers, and Enterprise BlatUI components.

🏛️ Enterprise N-Tier Architecture & Recursive Discovery

Support for 3-tier and recursive slice hierarchies (SuperDomain / Domain / Slice) up to 6 levels deep. Extended manifests with super_domain, domain, sub_domain, table_prefix, and dynamic PSR-4 namespace calculation matching folder taxonomy.

🏢 Pluggable Multi-Tenancy & SaaS Isolation

Native TenantManager singleton, HasTenant Eloquent trait with automatic TenantScope query registration, and IdentifyTenant middleware supporting header, parameter, and session-based tenant resolution.

🚀 Universal Monolith Reverse-Engineering & ETL Data Streaming

Introspect massive 200+ table legacy databases (tested against 227-table ERP). Multi-block migration parser, foreign-key dependency analysis, dynamic master taxonomy seeder synthesis (zero blank dropdowns), and high-throughput ETL data streamer (SliceDataPortService) with auto-ID preservation.

🎨 Blueprint Studio Porting Suite & 1-Click Canvas Loading

Interactive Porting Studio modal with live side-by-side architecture preview, live BlatUI sidebar preview with record badges, and 1-click loading of 28 bounded slices directly onto the Blueprint Studio canvas with full model schemas, fields, and 4-step BlatUI plans.

📑 Declarative UI Schema, Instant Drawers & Modular YAML

Canonical ui: schema block with presentation (slide-over drawer with ?drawer=create deep-linking), directory formatters (code_badge, composite_user, status_pill, money_breakdown), forms section grids, and granular modular validation (php artisan slice:validate --part=ui|forms).

🛡️ Enterprise BlatUI Upgrades, Defensive Migrations & RBAC Matrix

Top-header Module Switcher Ribbon with reactive Alpine.js filtering, multi-select bulk actions in <x-ui.data-table>, defensive migration table guards (Schema::hasTable), 250 enterprise field capacity, and hierarchical RBAC permission matrix.

v1.6.1 October 12, 2026

Feature release introducing the Vertical Slice Workflow State Machine Engine, visual lifecycle progression components, dual-flow statutory adjudication and intake architecture, and production enterprise porting refinements.

⚡ Vertical Slice Workflow Engine & Visual Components

Native lifecycle state machines with HasWorkflow trait, WorkflowEngineService, stepper progression bars, timeline audit trails, role-scoped permission guards, and forward-with-remarks action modals.

⚖️ Dual-Flow Statutory Adjudication Architecture

Production-grade separation of Admin Docket Intake (inward mode, courier tracking, diary timestamps) and Public Grievance Portals, multi-stream statutory routing, dynamic property repeaters, and multi-respondent accused management.

📦 Enterprise Monolith Porting Refinements

Automated taxonomy seeder extraction, scoped child-table navigation hierarchy, atomic cascade cleanup on slice removal, and the built-in Dispute Adjudication Suite enterprise preset in Blueprint Studio.

v1.6.0 October 2026

Major milestone introducing the Monolith Reverse-Engineering & Legacy App Porting Pipeline, enabling automated translation of complex monolithic Laravel codebases into cleanly decoupled Vertical Slices grouped under Bounded Domains, complete with dual-mode data migration and interactive mapping.

🚀 Reverse-Engineering Classification Engine (`SlicePortService`)

Automatically parses legacy models, schemas, and migrations (e.g. 51+ flat tables). Categorizes tables into Aggregate Roots, Child entities, Reference Taxonomies, and Many-to-Many Pivots, structuring them directly into domain YAML blueprints.

🌱 Dual Data Porting: System Base vs. Full Production Migration

System-Base Mode: Scans legacy database tables for master lookups, 24 statuses, categories, offices, and generates deterministic seeders in database/seeders/ to guarantee 0 blank dropdowns on clean slate installs.
Full-Data Mode: Performs complete topological table migration preserving primary/foreign key hierarchies and copies physical file attachments from legacy storage/app/public.

🖥️ Interactive Visual Studio Mapping & 1-Click Porting

Integrated Port Legacy App modal in Blueprint Studio (/laraslice/wizard/blueprint) and Quick-Launch banner in Wizard (/laraslice/wizard?port=1). Offers live side-by-side Table-to-Slice Architecture previews with verified schema introspection before executing migrations.

🤖 Conversational AI Porting Protocol

Standardized protocol in SKILL.md instructing AI assistants (Antigravity, Cursor, Claude Code) to proactively prompt developers for project path, target domain context, and preferred data mode before command execution when operating outside the GUI.

v1.6.0 October 2026

This milestone release brings live MySQL column reflection, conversational 1-click migrations, the visual Slice Studio orchestrator, an enterprise 15-table User aggregate with WebAuthn passkeys, and real-time DOM screen awareness.

⚡ Visual Slice Studio (`/laraslice/wizard/studio`)

Dedicated visual command center for browsing slices, aggregate entities, and live records. Features a bidirectional event bus (laraslice-slice-selected) that instantly syncs selected slice context, tables, and permissions directly into the Copilot.

📐 Real-Time MySQL Column Introspection ("What You Ask is What You Get")

The AI Copilot executes native SHOW COLUMNS FROM `{table}` queries, revealing exact SQL data types, nullability, primary/foreign/unique keys, and default values. Eliminates guesswork when querying specific tables like user_details.

➕ Conversational 1-Click Schema Migrations in Chat

Ask to add a field (e.g. "add emergency_contact in user_details"). The Copilot displays an interactive proposal card with inferred data types, non-breaking nullable defaults, enterprise recommendation chips, and a single-click "⚡ Apply Migration & Add Field Now" button that generates and runs the migration on MySQL immediately.

⌨️ Dynamic Context-Aware Slash (/) Commands

Typing / in the Copilot auto-completes slice-specific actions: /fields [table], /add-field [table], /relations, /permissions, /nav, /logs, /suggest-fields, /seed, and /wipe.

👥 Enterprise User Management Aggregate (15 Tables)

Upgraded the Users slice to a full multi-table aggregate: primary users root table with 14 child entities including user_details, user_devices, user_passkeys (WebAuthn/FIDO2 biometric login), and user_security_logs.

🛡️ Passkey Revocation & Safe Lifecycle Flow

Fixed passkey removal routing to support multi-verb dispatch (DELETE/POST/GET) and seamless redirection back to the MFA settings hub with live status alerts.
